## Overview

Test workflows and rule demonstrations.

## Core Functionality

- Pass/fail examples for each rule
- Documentation for each rule
- Real n8n workflow format
- Used by web UI and tests

## Structure

Each rule (R1-R14) has:
- pass.n8n.json - Correct workflow
- fail.n8n.json - Problematic workflow
- README.md - Explanation
